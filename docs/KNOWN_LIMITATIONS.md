# TateClipの既知の制限

この文書は、現在の実装を評価・利用する前に共有しておくべき制限をまとめたものです。GitHubでのソース公開と、将来の一般ユーザー向けbinary配布は別のrelease gateとして扱います。

## AI解析

- AI候補は完成品ではなく「初稿」です。
- ゲーム音が大きすぎる動画では、実況音声の検出精度が落ちる場合があります。
- マイクとゲーム音が同一トラックの場合、字幕や盛り上がり判定が不安定になる場合があります。
- 解析結果キャッシュは「最終結果」の復元が中心で、ステージ別の完全キャッシュではありません。
- 解析ジョブログで現在ステージと直近ログを確認できます。
- 解析キャンセルは対応していますが、停止タイミングはWhisper/FFmpegの現在処理が次のチェックポイントに進んだ時になります。
- 失敗チャンクだけの自動再試行は未対応です。

## 字幕

- 字幕は必ず人間の確認を前提にします。
- 低信頼字幕や幻覚疑いの字幕には確認フラグが付きます。
- 発声していても字幕が抜ける場合があります。
- 無音・笑い声・ゲーム音・叫び声の区別は素材によって不安定です。
- 自動字幕の句読点や表記ゆれは手直し前提です。
- 複数音声トラックの動画では、声トラック/ゲーム音トラックの判定結果をAI初稿パネルで確認してください。

## ラフカット判断

- クリップのKEEP／没、分割、IN／OUT調整、削除、並び替えができます。
- TateClipは完成動画の演出を行う動画編集ソフトではありません。テロップ、カラー、トランジション、BGM、SE、合成などの仕上げは受け渡し先のNLEで行います。
- 旧 `.vfocus` の編集情報は互換性のため読み込めます。書き出し画面で明示的にラフカットへ切り替えると、速度・変形・演出・追加素材を外します。
- 元動画が横、縦、正方形のいずれでも解析とラフカット判断ができます。出力尺に15秒・30秒・60秒などの固定上限はありません。
- 字幕はNLEへ渡すSRTとして出力できます。TateClipのラフカット動画へ字幕を焼き込みません。
- 編集中プロジェクトはアプリデータへ自動保存され、次回起動時に復元または破棄を選べます。20MBを超えるプロジェクトは手動保存が必要です。

## 受け渡し・書き出し

- 元動画の幅・高さ・FPSを維持します。縦横変換、黒帯追加、リフレームは行わず、次の動画編集ソフトへ任せます。
- MP4 / MOVのラフカット動画と、JSON / CSV / CMX 3600 EDL / SRTを出力できます。
- CMX 3600 EDLは単一ソースのストレートカット用です。複雑なトランジション、速度変更、複数カメラ、ドロップフレーム時刻は表現しません。
- EDLの対応状況はNLEごとに異なるため、DaVinci Resolve、Premiere Pro等への実インポート確認が必要です。
- FFmpegの失敗は素材形式やパス、フィルタ構成に依存します。
- 書き出し後に映像ストリームと先頭フレームを検証します。検証に失敗した音声だけ・0フレームなどの不完全動画は残しません。
- 一部の特殊な動画形式、可変フレームレート、壊れたメディアでは失敗する可能性があります。
- GPUエンコードは環境によってCPUフォールバックになる場合があります。
- ラフカット動画は単一映像・元音声の確認用です。追加トラックや演出は焼き込みません。

## 環境

- まずWindows環境を優先します。
- 一般配布用の軽量版は初回起動時に約140MiBの公式FFmpeg ZIP、初回のAI字幕利用時に約1.51GiBのモデル取得が必要です。どちらも途中中断と再開に対応します。
- FFmpegとモデル取得後の編集・AI解析は端末内で行います。完全にオフラインで導入する場合は社内・検証用フル版を使用します。
- Tauriデスクトップ環境での動作が前提です。
- ブラウザプレビューではAI解析や書き出しは完全には確認できません。
- Pythonデーモン、whisper.cpp、FFmpegの状態によってAI解析の可否が変わります。
- 実行環境チェックからdaemon診断ログをコピーできます。解析や起動で詰まった場合はこのログも確認します。

## 未署名配布

- 初回公開版はAuthenticodeコード署名を行わない方針です。
- Windows Defender SmartScreenやユーザーアカウント制御で「不明な発行元」の警告が表示される場合があります。
- この警告をアプリ側の実装で消すことはできません。
- 一般ユーザー向けbinaryを配布する場合は、発行元警告、正規の配布URL、各artifactのSHA-256を配布案内に明記します。GitHubソース公開とは別のrelease gateで確認します。

## 第三者コンポーネント

- whisper.cppとOpenAI WhisperモデルはMIT Licenseです。配布物に`THIRD_PARTY_NOTICES.txt`を同梱します。
- FFmpegはLGPL-3.0-or-laterです。軽量版はMSIへ同梱せず、`release/ffmpeg-source.json`で固定したBtbN公式GitHubリリースから直接取得してZIPとEXEをSHA-256検証します。出所とソース情報は同梱noticeとprovenanceにも記録します。

## 現時点で許容すること

- UIが多少荒い
- 字幕が手直し前提
- 一部動画で解析が遅い
- キャンセルが即時ではなく、数秒〜処理単位で遅れて止まることがある
- 一部機能が未完成
- エラーが出るが、診断情報で原因を追える

## 現時点でも許容しないこと

- アプリが起動しない
- 動画を読み込めない
- 書き出しが常に失敗する
- 出力動画が壊れる
- 失敗理由がまったく分からない
