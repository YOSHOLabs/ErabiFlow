## MANUAL TEST REQUIRED: NLE受け渡し

1. 元動画を移動せず、Resolveの新しい空プロジェクトを作ります。
2. 元動画と同じFPSでタイムラインを設定し、MP4をMedia Poolへ読み込みます。
3. MP4の画角、順序、区間の境界、音声、長さを確認します。
4. EDLをタイムラインとして読み込み、必要なら元動画を再リンクします。区間と時刻をMP4と比較します。
5. SRTを読み込み、ラフカット時間軸で字幕の日本語・開始終了を確認します。
6. JSON/CSVのsource区間、順番、長さを出力と比較します。これらは汎用データで、NLE直接importを保証しません。
