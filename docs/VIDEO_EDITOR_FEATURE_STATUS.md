# TateClip 旧動画編集機能の互換性インベントリ

更新日: 2026-08-09

> この文書はv14以前のプロジェクトを壊さず読み出すための旧機能インベントリです。現在の製品UIはKEEP／没、IN／OUT、分割、順番とNLE受け渡しに絞っており、以下の合成・装飾機能を新規ラフカットの製品機能として提供しません。

この文書では、操作ボタンだけ存在する状態を「実装済み」としない。プレビュー、プロジェクト保存、FFmpeg書き出しまで同じ結果になる機能だけを実装済みとして扱う。

## 現在使える機能

### プロジェクト

- 新規プロジェクト
- `.vfocus`プロジェクトの保存・読み込み
- 別名保存によるプロジェクト複製
- 復旧用の自動保存
- Undo / Redoとプロジェクトスキーマ移行

### 素材とタイムライン

- 動画・画像・音声の複数選択読み込みと再利用できる素材ライブラリ
- 仮想フォルダ作成・移動・名前変更・削除、お気に入り絞り込み
- 動画ごとの軽量プロキシ生成・再利用・削除とプレビュー自動切り替え
- 旧プロジェクトの動画・BGM・画像を素材ライブラリへ自動移行
- 画像オーバーレイ、BGM、元動画への素材配置
- 映像、元音声、BGM、画像、字幕、効果音の専用レーン表示
- クリップのカット、分割、トリミング、削除、複製、並べ替え
- リップル削除とGap置換
- クリップ端・ワーク範囲・BGM端へのスナップ
- フレーム単位の移動
- V2/A2以降の任意トラック追加・削除、ロック、映像表示、音声ミュート
- 複数クリップのグループ化、グループ移動、コピー・貼り付け

### クリップ編集

- 0.25x〜4xの速度変更
- 拡大縮小
- 横・縦位置調整
- -180°〜180°の回転
- 左右反転・上下反転
- 不透明度
- クリップ固有音量とミュート
- 位置・拡大率・回転・不透明度・音量キーフレーム（線形／保持補間）
- フェード、ディゾルブ、スライド、ズーム、回転の開始・終了トランジション
- 明るさ、コントラスト、彩度、色温度、色かぶり、ハイライト、シャドウ、黒／白レベル、HSL、3点カーブ、`.cube` / `.3dl` LUT
- シネマ、フィルム、レトロ、モノクロ、ビンテージ、クール、ウォーム、HDR風フィルター
- ブラー、モザイク、モーションブラー、シャープ、ノイズ、VHS、フィルム、グリッチ、RGB、発光、ライトリーク、レンズフレア、雨、雪、炎、パーティクル、手ブレ、ワープ、色収差
- クロマキー、円・楕円／四角マスクとフェザー
- スイング、バウンス、ポップのクリップモーション
- 3点カーブ速度、映像・音声の逆再生、フリーズフレーム
- 3帯域EQ、ラウドネス正規化、ノイズ低減、フェードイン／アウト

速度変更はシーケンス長、再生位置、字幕位置、音声テンポへ連動する。映像変形、カラー、エフェクト、キーフレーム、音声補正はプレビューだけでなくFFmpeg書き出しにも反映される。LUTだけはCanvasで完全再現できないため数値補正をプレビューし、最終書き出しへ正確に適用する。

### 縦動画制作

- 1080×1920 / 9:16キャンバス
- 横素材を帯状に置く構図、ゲーム実況向けの上下黒帯つき3:4クロップ、人物・商品紹介向けの画面いっぱい9:16クロップ
- 背景ぼかし
- ゲーム映像の全体位置・拡大率
- AIオートリフレーム用の構図データ
- 通常テキスト、字幕、字幕個別スタイル、単語追従ハイライト
- タイトル／字幕向け6種類のスタイルプリセット
- アバター・画像オーバーレイ
- 絵文字、イラスト、デコレーションの透明ステッカー生成
- 合成・リアクション編集ツールで、別動画を左上／右上小窓、楕円切り抜き、下段2画面、全面カットアウェイとしてV2へ追加
- 配置後のV2は、表示時間・素材範囲・位置・大きさ・回転・マスク・速度・キーフレーム・色・エフェクト・音声を個別編集
- 本編クリップへパンチズーム、横振り、回転イン、衝撃、白黒を独立して追加し、追加後も数値調整可能
- MediaPipe MagicTouchによる画像のAI背景除去・人物／オブジェクト切り抜き
- BGM、効果音、音量、ダッキング
- マイクのナレーション録音と音声素材への保存
- 文章・Windows音声・速度を指定するオフライン音声合成／読み上げとWAV素材化
- SRT読み込み／書き出し、話者ラベル、Whisper英語翻訳字幕
- MP4 / MOV / GIF / PNG連番
- H.264 / H.265、解像度、FPS、ビットレート設定
- 4隅配置・フォント・色・サイズ・不透明度を指定できる任意テキスト透かし
- TikTok、Instagram Reels、YouTube Shorts向けの任意の投稿メモとUI回避ガイド

## 制約がある機能

- テンプレート: 縦動画の構成テンプレートはあるが、編集済みレイヤー一式を保存するプロジェクトテンプレートではない
- クロップ: 9:16向けクロップとパン・ズームはあるが、自由矩形クロップUIではない
- オートリフレーム: AI検出データを使った中心調整はあるが、キーフレーム追従編集UIはない
- ショートカット: 基本操作はあるが、割り当て変更UIはない
- 話者分離: 音声トラックが分かれている素材はトラック番号を使う。1本に混ざった音声は発話間隔による推定ラベル
- 翻訳字幕: 同梱Whisperの翻訳モードで英語字幕を再生成する。任意言語間翻訳モデルは未同梱
- マスク: 現在の編集UIは円・楕円と四角。自由パスは未実装
- ディゾルブ: 現在はクリップ端の緩急付き透明度変化。隣接クリップを重ねるクロスディゾルブは未実装
- 透かし: 現在はテキスト透かし。画像ロゴ透かしは通常の画像オーバーレイで代用する
- AI切り抜き: 現在は静止画像をクリック指定して透過PNG化する。動画全フレームの人物追従切り抜きは未実装
- 音声合成: Windowsにインストールされた音声を使う端末内合成。クラウド型の声質学習やボイスクローンではない

## 高費用対効果の追加実装

- 8種類のフィルタープリセットを、素材に依存しない数値カラー補正として実装
- タイトルと字幕それぞれへ6種類の読みやすいスタイルプリセットを実装
- 縦動画で使用頻度の高いズーム／回転トランジションを実装
- 任意テキスト透かしを、プレビュー・プロジェクト保存・Undo/Redo・FFmpeg書き出しへ実装
- 高度カラー、17種類の追加映像エフェクト、3種類のモーションをプレビュー・保存・FFmpeg書き出しへ実装
- 絵文字／図形ステッカー、オフライン読み上げ、クリック指定AI切り抜きを再利用可能な素材生成として実装
