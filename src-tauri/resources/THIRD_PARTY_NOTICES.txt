ErabiFlow Third-Party Notices
============================

FFmpeg
------
ErabiFlow invokes FFmpeg as a separate executable for media decoding, analysis,
and export. The lightweight application build downloads an unmodified LGPL build
directly from the fixed BtbN/FFmpeg-Builds GitHub release recorded below,
then verifies both the release archive and extracted executable with SHA-256.
ErabiFlow does not claim ownership of FFmpeg.

FFmpeg project and license information:
- https://ffmpeg.org/
- https://ffmpeg.org/legal.html
- https://www.gnu.org/licenses/lgpl-3.0.html
- https://github.com/BtbN/FFmpeg-Builds/releases/tag/autobuild-2026-06-30-13-34
- https://github.com/FFmpeg/FFmpeg/commit/9a01c1cb6a4cf87529fe9898b66ec55c5b032639

Exact artifact and source hashes are recorded in release/ffmpeg-source.json in
the ErabiFlow source tree.
