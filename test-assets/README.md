# TateClip local test videos

このフォルダは、実メディア動作確認用のローカル動画置き場です。

ここに置いた動画ファイルは `.gitignore` でGit管理対象外にしています。配信者名、個人情報、限定公開素材などが混ざる可能性があるため、共有前提のファイルは置かないでください。

## 推奨サンプル

最低1本:

- `main-gameplay.mp4` — 5〜15分程度の普通のゲーム実況

余裕があれば:

- `single-audio-track.mp4` — マイク音とゲーム音が同一トラック
- `separate-audio-tracks.mp4` — マイク音とゲーム音が別トラック
- `noisy-game-audio.mp4` — ゲーム音が大きめ、声が小さめ

## 見るポイント

- 動画読み込み
- AI初稿生成
- 字幕欠落
- 低信頼/幻覚疑い字幕のフラグ
- 候補採用
- トリム/分割/削除
- 横・縦素材の元画角を維持したラフカット書き出し
- JSON／CSV／CMX 3600 EDL／SRTの受け渡し
- 出力動画の音ズレ、字幕ズレ、クロップ崩れ
